# RFCs

Design proposals for Forze. Shipped RFCs are retired from this directory once their
work has landed — the code, tests, docs and changelog carry the record from then on.
What lives here is what is still open: drafts, parked designs, and partially executed
work.

## Allocating a number

The next free number is **0043**. Before creating an RFC, glance at the table below
(or `ls rfcs/`) and take the next unused integer — numbers collide when minted in
parallel. Update this table in the same change.

Filename: `NNNN-kebab-title.md`. Keep the `# RFC NNNN — Title` H1 and the number in the
filename in sync.
