Recorded markers reach the recorder — a probe patched around the handler sees `contract` events
accumulate — and do not reach the history the report carries, which holds only `op_start`,
`trace` and `operation`. An empty-`violations` `ViolationReport` is itself a contradiction: the
sweep found something and the object describing it says it did not. Both belong to
`forze_dst`'s minimize-and-replay path rather than to this RFC, and neither is a reason to ship
a leg whose oracle is silent.

`no_overlapping_periods` keeps its own battery over hand-built histories, which is where its
behaviour is pinned; what moved is only which oracle this kit's simulation leg drives.
