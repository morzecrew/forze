## Self-audit — 2026-09-12

Scope: the whole branch against merge base `3d3182921`, 2 commits / 8 files / +316-18.
Eight sabotages, each proven to change behaviour before its verdict was read. Two survived
and both cost code rather than tests.

**A-1 · The helper deduplicated the selection; nothing needed it.** `planes=["authn",
"authn"]` was collapsed before registration on the stated grounds that registering one spec
twice is refused. It is not: re-registering with identical metadata is idempotent, and
`source` alone never conflicts, which the registry documents. Measured — six specs passed
twice yield six entries — and the deduplication is gone. The test now says which layer
makes a repeated plane harmless instead of crediting this function for it.

**A-2 · The helper ordered the selection; nothing needed that either.** `freeze()` sorts
entries, so a caller's spelling could never reach a fingerprint, and the comment claiming
otherwise was wrong. Removed, and the order test now asserts the fingerprint equality it
was really about and names `freeze()` as the guarantee.

**A-3 · The docs understated §5.2 by calling the coupling a caveat.** The authn module's
`eligibility` defaults to `"policy_principal"`, so the gate that reads
`authz_policy_principals` is **on unless the application opts out** — which makes
`planes=["authn"]` alone the failing case by default rather than the working one. Both
pages and the helper's docstring now pair the selection with `eligibility="allow_all"`
explicitly. The RFC's origin application was right about itself and the wording
generalised it wrongly.

**Coverage:** 100% of `forze_identity.inventory` and
`forze.application.contracts.inventory.reconcile`, statements and branches.

**Drift count: 0.**

## Residue at hand-off — 2026-09-12

**The RFC says twelve documents; it is thirteen.** An authn-only application cataloguing
all three planes gets eleven authz plus two tenancy specs refused. Measured, pinned by
`test_the_unnarrowed_helper_is_what_refused`, and left as written in §1 and §2 — the origin
application may genuinely bind one of them, and amending the prose would erase the
motivation's own record.

**A tenancy-only or authz-only application is still untested beyond the unit case**, as §8
says. Both are legal selections; no such application has been seen, and nothing here
changes that.

**The hint is generic, and sometimes it will be noise.** It names a narrowed contribution
helper on every bound-but-uncatalogued failure, including the many that are a plain
forgotten spec — `forze.application` cannot name `forze_identity`, so the message cannot
be conditioned on the cause. §10 accepted a sometimes-wrong hint; this is that cost, paid
on both refusal sites.

## Self-audit round 2 — 2026-09-12

Round 1 read the diff; this round read the *surface* the diff creates, which is where it
had missed three things.

**A-4 · The type in the public signature was not importable.** `planes` is typed
`Sequence[IdentityPlane]` and `IdentityPlane` was not exported from `forze_identity`, so a
caller annotating a selection could not name the type of the argument the function
advertises. Exported.

**A-5 · §7's second bullet was never done.** It asks for the narrowing note "wherever
`build_runtime(specs=…)` is documented"; round 1 wrote the reference page and left the
`:param specs:` docstring — the copy a reader sees from their editor — untouched. Added.

**A-6 · Exporting meant hand-editing three lists with no gate watching them.** The
front-door battery (`test_public_api.py`) covered `forze` and `forze_kits` and not
`forze_identity`, which has the same lazy PEP 562 shape. Parametrized over all three;
dropping the new name from the resolver map now fails three cases. Nine sabotages total,
eight killed, and the two survivors from round 1 are the dead code that was removed.

**A-7 · The `Literal` has one ergonomic edge, and it is now written down.** A selection
held in a `list[str]` is not a `Sequence[IdentityPlane]`; measured under `mypy --strict`,
where the inline list, a tuple and an annotated `list[IdentityPlane]` all pass and the
bare `list[str]` genuinely needs an ignore. The parameter doc says to annotate the
constant. Row 6 keeps the `Literal` — the alternative was inventing a plane enum for a
three-member keyword.
