# T-0075 — Realtime connection drain

Executing all three phases of [RFC 0075](../rfcs/0075-realtime-connection-drain.md) on
`feat/connection-drain`, stacked on `feat/drain-announcement` (RFC 0074): a socket.io drain
phase that closes this replica's selected Engine.IO connections spread over a window, a
refusal while the replica drains, connection metrics, an `admission` hook on connect, and the
same drain for the FastAPI SSE and WebSocket live tails through their shared hub.

The author is unavailable for this run. Per the orchestrator's rules, `ASSUMED` rows the code
contradicts are departed from and logged, `OPEN` rows and unlisted gaps are decided and logged
with a proposed row, and a `LOCKED` row the code contradicts would be logged `halted`. The
readiness gate's stop-at-three is waived by those rules; the gaps below are decided rather
than escalated.
