## Readiness: the gate trips, and the RFC says why

RFC 0026's decision log is **empty by design** — "this RFC records a measured problem, not
yet a resolution" — and §4 lists four candidate designs with none chosen. Against this
skill's readiness threshold of three load-bearing unsettled decisions, that is a halt:
which design, whether fragments get a declared fence, and whether the ratchet reuses the
exemption table are all load-bearing, and executing past them would produce a second,
undocumented design expressed in code.

But the RFC also names what has to happen first, and it is not a decision: §5 Q1 asks what
fraction of the 271 blocks would pass a compile check today, and §3 says the cheap bar
"may catch most of the value; that is a claim this RFC should test against the 271 blocks
before committing". That is the `irreducible` class — no amount of design settles it — so
the action is to spike and ship the information rather than the code.

## Self-audit — 2026-09-12

Scope: the whole branch against merge base `9ac2f8959`, 11 files / +799-7. Six sabotages
against the gate's own failure modes, all killed — one of them only after a second attempt,
because the first patch never applied and its "24 passed" was a no-op mutation rather than
a survivor.

The findings are the ones sabotage cannot reach.

**A-1 · The gate reached 41% of the calls and its summary read as if it reached all of
them.** `445/445 call(s) match their signature` counted only bare imported names. Measured
over the corpus: 458 of 1108 calls checked, 387 attribute calls skipped, 263 bare names
that were never imported from forze. A third of the skipped attribute calls turned out to
be resolvable with the machinery already present — `DepsRegistry.from_modules`,
`LifecyclePlan.from_modules`, `exc.domain` are one attribute deep on an imported symbol —
so the bar now resolves those too, 507 calls, and the summary states how many it skipped.
What stays out of reach is a call on a local instance (`runtime.scope()`), which needs to
know what the local was assigned.

**A-2 · An unreachable branch.** `_callee_name` carried an `ast.unparse` fallback for a
callee shape `_callee` had already refused, so it could never run — coverage found it, and
a branch nobody can test is a branch nobody should read. The two dispatches over the same
callee shapes are now one: `_callee` returns the name with the target.

**A-3 · The resolution-failure path was uncovered.** A block whose forze import is broken
reaches `_imported_callables`, whose `except` keeps the call bar quiet because the import
bar owns that finding. Nothing exercised it; now a test does, and asserts the two bars
split the report rather than double-counting it.

**A-4 · The violation message buried what a reader acts on.** It printed the full signature
with fully-qualified annotations — over 400 characters for the motivating case, with
`missing a required keyword-only argument: 'retention'` at the end of it. Annotations are
stripped now: `build_realtime_mailbox(ctx, *, retention, spec=None, cap=1000,
replay_page_size=100)`.

**Injected the regression the gate exists to catch**, rather than trusting the synthetic
unit case: `build_realtime_mailbox(ctx)` appended to the real `data-events/realtime.md`,
where it originally shipped, and `just docs-snippets` failed naming the file, the line and
the missing keyword. Removed again, green.

**Coverage:** 100% of `tools/docs_snippets.py`, statements and branches.

## Residue at hand-off — 2026-09-12

**The gate finds nothing today, and that is the expected result.** Every candidate design
in §4 assumed a stock of failing blocks to work down; there was none. Its value is the next
regression failing CI, so a green first run is not evidence the extractor is broken — which
is why an empty denominator is itself a failure here.

**59% of calls in the docs are still unchecked**, and the largest remaining group is
`ctx.<plane>.<method>(...)` — the single most-used shape in the corpus. Reaching it needs
to know what `ctx` is, which is type inference rather than symbol resolution. A cheaper
half-step exists if it is ever wanted: `ExecutionContext`'s attributes are typed, so a
callee rooted at a parameter annotated `ExecutionContext` could be resolved without
inferring anything. Not built, and not proposed as a row — nothing has asked for it.

**Values are never checked, by design.** A snippet that passes `cap="ten"` binds fine. The
bar is that the call *shape* is current, not that the example would run.

**§1's counts are left as written.** The RFC records 271 inline blocks and 81 included; the
gate counts 337 and 85 today. Correcting the prose would erase the measurement the RFC was
arguing from, and the drift is itself the argument for the gate.

**A-5 · The filter's output was never exported.** Fixing the filter was not enough: the
`changes` job's `outputs:` block did not list `docs`, so `needs.changes.outputs.docs`

## Review round 1 — 2026-09-12

Three findings, all on this branch's own code, all valid, each reproduced before any fix.
The second one paid for the round twice.

**R-1 · The workflow guard's reference pattern truncated names.** `[a-z_]+` stopped at the
first digit, so `needs.changes.outputs.docs2` read as a reference to `docs` — a declared
output — and the guard added last round passed on exactly the wiring it exists to catch.
Proven as a differential: with an undeclared `docs2` reference planted in `ci.yml`, the
narrow class passed and `\w+` fails. The pattern is a named constant now, so the claim is
testable without mutating the workflow.

**R-2 · The elision exemption read the unparsed source, so a string widened it.** `"..." in
source` matched any call whose text contains an ellipsis, including one inside a string
argument, and skipped the whole call. Now read off the arguments: an `Ellipsis` among the
call's own args or keywords.

**And that hole was hiding a real broken snippet.** With the fix in place the gate
immediately failed on `recipes/rotating-oauth-credentials.md:92` — a `PostgresDepsModule`
wiring example missing its required `client`, skipped until now because a nested
`CrmTokenExchanger(http=...)` put an ellipsis in the outer call's text. A wiring example is
the most copy-pasted kind, so it is repaired rather than marked. This is the first defect
the gate has found in the corpus, and it was found by fixing the gate.

**R-3 · Plain `import forze_x` bound nothing for the call bar.** The import bar already
read those statements, so the two bars disagreed about what a block had imported and every
call through a module alias went unchecked. Both forms now bind, plain and `as`-aliased.

Two sabotages, one per code fix, each killing its test; `ci.yml` was restored from a copy
rather than `git checkout --`, which has wiped uncommitted work three times this week.
