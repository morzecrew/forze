## Self-audit findings — 2026-09-09

Adversarial pass over the branch after execution: 1 commit, 9 files, +955/-177. Ranked by
what they cost; all fixed on the branch.

**1 · Closing the stream did not kill the child.** The abandonment contract this log locks
as decision U4 was written and did not work: `GeneratorExit` is not `CancelledError`, so
closing the generator reached no `except` clause and the kill never ran. A caller who broke
out of the loop left the child running and its workspace removed underneath it. The kill
moved into the `finally`, where every path reaches it.

**2 · Every route with a ceiling died of `SyntaxError`.** The shim source carried a broken
escape, so the child that was supposed to set rlimits could not be parsed. Caught by the
first ceiling test rather than by reading — the failure surfaced as `MemoryError` missing
from stderr, which reads like a limits problem and was a quoting one.

**3 · A `run_as_user` no such host has escaped as a bare `KeyError`.** `getpwnam` raises it
from inside the spawn, before any fork, and the adapter caught only `OSError` and
`ValueError` — so a wiring mistake propagated as an exception the contract says only
framework failures may raise. It is a `spawn_failed` result now, like every other child that
never started.

**4 · The `kill_grace` validation became dead code.** An edit anchored one block too far and
left the check after a `return`, where it could never run. The test that had pinned it since
P1 is what noticed.

**5 · A descendant that ignored `SIGTERM` was never `SIGKILL`ed.** Found by sabotage: the
branch that re-signals the group once the leader has exited had no test, because the
existing grandchild test always ended with the leader still alive. A descendant that
installs a `SIGTERM` handler and keeps running now has its own leg.

**6 · The multibyte streaming test was vacuous.** Also sabotage: decoding each read on its
own passed it. `é` is two bytes and the read is 64 KiB, so every chunk boundary fell neatly
between characters and the incremental decoder was never exercised. A single-byte prefix
puts the boundary mid-character, and a byte-level test drives the case a real pipe will not
produce on demand.

**One equivalent mutant, proven rather than assumed.** Keeping the first result event
instead of the last survives, because `_execute` yields exactly one — every `yield` of a
result event is followed by a return or ends the generator. The streamed test now asserts
that count, so the property the mutant relies on is pinned rather than incidental.

**Evidence.** `just quality` 18/18 green. Sabotage: 20 mutations, 19 killed, 1 equivalent.
Patch coverage of the sandbox modules 100% of statements and 100% of branches.

**Drift count: 0.** Six unlisted decisions, no departures: nothing here contradicts a
decision the RFC made.

## Self-audit round 2 — 2026-09-09

Two findings, both about where a guarantee lives rather than whether it works.

**1 · The streaming abandonment contract lived on the adapter.** A caller writing the
`break` cannot see which adapter it is talking to, so "closing the generator ends the run"
belongs on the port beside the method it constrains — along with the fact that there is
exactly one result event and it is the last, which a consumer keeping the newest one it saw
is already relying on.

**2 · The DST cut had no streamed leg.** The seam is the port, not one of its two methods:
without a test, `run_stream` was the way round a refusal `run` trips. Pinned on the same
ground.

Also simplified `_signal_group`'s exception tuple, which listed two subclasses of the class
beside it.

**Drift count: 1.** Unchanged; neither finding is a departure.

## Self-audit round 3 — 2026-09-09

**A request could not narrow the ceilings it was allowed to ask for.** `ResourceRequest`
says plainly that a request narrows its own budget and is clamped to the route's ceilings,
and `wall_clock` and `max_output_bytes` were the only two that honoured it. A request
setting `memory_bytes` against a route that *does* impose a memory ceiling passed the
capability gate — the ask is legitimate, the route imposes that ceiling — and was then
dropped, so the caller believed the child was capped where it asked while it ran at whatever
the route allowed. The same silent degradation the capability model exists to forbid,
reached by one extra step.

Narrowed by `min` now, never widened, and the CPU pair keeps its gap between soft and hard:
collapsing them would skip the `SIGXCPU` that makes it the one over-run this tier can name.

**Drift count: 1.** Unchanged.

## Self-audit round 4 — 2026-09-09

**1 · The streamed chunk queue was unbounded.** A consumer falling behind did not slow the
child: the reader drained the pipe as fast as it could be filled and parked everything in
the worker, which is the pipe's own regulation defeated by the thing draining it. Bounded
at eight chunks, so the kernel's backpressure reaches the child again.

**2 · Bounding it the obvious way deadlocked, and the suite hung rather than failed.** With
a maximum size, a reader cancelled while blocked on a full queue runs its `finally`, and the
`await put` of the end-of-pipe sentinel there blocks forever on a task that is already
cancelled — leaving the drain waiting on a reader waiting on a consumer that has stopped.
The sentinel is gone entirely: the pump races a queue read against the reader *tasks*, so
there is no message left to lose. Worth recording as its own finding rather than folding it
into the first, because the fix for an unbounded buffer is where this class of hang comes
from.

**3 · A branch written defensively was unreachable.** The tail drain after the readers
finish cannot run: every put happens before a reader returns, so if anything were queued the
pending get would have completed and taken the other branch. Deleted rather than kept,
which is the same call this branch made about `capture_command` in P1.

**Sabotage, both sweeps.** 30 mutations over the two rounds, 28 killed. Three survivors were
real gaps and are now covered — the `_pump` queue's bound (the first test built its own
queue and so proved only that the reader blocks), the cancellation of the losing race
participant, and the re-signal after a leader exits on `SIGTERM`. Two survivors are
equivalent mutants, each proven rather than assumed: keeping the first result event instead
of the last, since `_execute` yields exactly one and a test now asserts that count; and
removing the `run_stream` capability check, since `supports_stream` is true for every
possible wiring of this adapter — pinned by a parametrized test so the guard's kept-for-later
status is stated rather than left for a reader to wonder about.

**Evidence.** `just quality` 18/18 green. `pytest` across the four sandbox suites: 172
passed. Patch coverage of the sandbox modules 100% of statements and 100% of branches.

**Drift count: 1.** Unchanged across all four rounds: one departure, recorded in the first
section of this log, and no others.
