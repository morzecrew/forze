## Readiness: the gate does not trip

Six decision rows, all graded `locked` in lowercase, so every one is read as `LOCKED` and
any contradiction halts. They settle the names, the two-field split, the wiring guard, the
span tag, and — in four "do not build" rows — the shape of everything this must not become.

other two are settled against in-repo precedent and owe rows back.

```divergence

claim: the RFC says the gate "tags the per-request OTel span" without naming which one, and no span belongs to forze_http — the per-call CLIENT span is built by core's generic port proxy from the *spec*, only when `with_otel_port_spans` is enabled, and that proxy never sees an integration's config
evidence: src/forze/application/execution/deps/port_instrumentation.py:98-131
action: decided
proposal: ASSUMED — the adapter sets the attribute on the current span inside `invoke`, beside the `propagate.inject` call it already makes. That tags the port span where port spans are on, the enclosing operation span otherwise, and is a no-op on an uninstrumented app. Plumbing an integration's config into the generic proxy would put one integration's concern on every port's path.
```

## Whether the inference configs delegate in this phase

```divergence
decision: unlisted
grade: UNLISTED
class: spec-gap
at: 2026-09-13T09:08:00Z
attempt: 1
claim: §1 contradicts itself within one paragraph — its "Scope of execution" sentence includes "the delegation from the inference configs", while the sentence above it and decision row 2 both say the inference configs "can later delegate". The semantics also differ: an inference route is unconditionally sensitive (acknowledge_data_egress must always be True) whereas the new gate fires only when egress_sensitive is set
evidence: src/forze_inference/http/execution/deps/configs.py:69-74
action: decided
proposal: ASSUMED — one shared validator, called by all three configs. The inference configs pass sensitivity fixed True and keep their own messages, so no existing wiring changes behaviour and "delegate to this one implementation" is satisfied without the deprecation "later" was protecting against. Reported to the author before execution as the item that changes the diff's size.
```
