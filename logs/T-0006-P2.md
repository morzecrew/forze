Executing [RFC 0006](../rfcs/0006-llm-adapters-token-streaming.md) phase P2 on
`feat/anthropic-messages-dialect`: a second generation dialect over Anthropic's native
`/v1/messages`, on the same kernel client, config and adapter. No SDK, no client, no extra.

Grades are copied from the RFC's §8 table as it stood at `a796ece4d`, where P2 was re-scoped
from a native provider client to this dialect (row 22).

`max_tokens` is required and the constraint is sent as `output_config.format` — so that row is
honored rather than departed from; the evidence is in the first entry below, which needed the
same lookup. The one departure is from row 4, whose "iff `openai_chat`" no longer describes a
plane with two generation dialects.
