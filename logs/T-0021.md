claim: §5 gate 2 defaults network to "none" and asks for an acknowledgment to enable egress, but a bare subprocess cannot restrict the network at all — its child has whatever the worker has — so an adapter declaring network="none" would be claiming an enforcement it does not perform, which the capability honesty rule forbids
evidence: rfcs/0021-sandbox-execution-plane.md:110 — "a declared capability without a test that exercises it is a lie"
action: decided
proposal: ASSUMED — `SubprocessSandbox` declares `network="egress"` unconditionally, so gate 2 requires `acknowledge_network_egress=True` on every route wired to it. The base adapter's simplest wiring therefore costs one explicit acknowledgment, which is the honest price of a child that can reach anything the worker can
