## Self-audit findings — 2026-09-09

Adversarial pass over the whole branch after execution: 1 commit, 25 files, +2954 lines
(three new source packages at 1,613 lines, four test files at 1,071, a docs page and this
log). Ranked by severity; all fixed on the branch.

**1 · An expired deadline became an unbounded run.** `remaining_time()` clamps at `0.0`,
and the budget was passed through `timeout=budget or None` — so the one case that most
needs a bound, a deadline already gone, produced *no timeout at all* and the child ran
until it finished. Reproduced: a run under an expired deadline never returned. The budget
is now computed before the workspace exists and a non-positive one returns `killed_cancel`
without spawning, which also keeps the deadline's story in one shape.

**2 · Ceilings the adapter cannot impose were silently ignored.** A request setting
`memory_bytes` against an adapter declaring `enforces_memory=False` ran with no limit and
said nothing. That is the silent degradation the capability model exists to forbid — every
other plane refuses up front, naming the feature and the backend. `validate_resources` now
does, in both the real adapter and the mock, so a route standing in for a backend without
memory ceilings fails under test exactly where production would.

**3 · A child ignoring its stdin killed the run.** `echo`, a script that reads only argv,
anything exiting early: the write raised `BrokenPipeError` out of `run()` — not even a
`CoreException`, against a contract that says only the framework's own failures raise.
Absorbed; the program declining to read is the program behaving normally.

**4 · The drain swallowed cancellation.** `except (asyncio.CancelledError, Exception)`
around each capture meant a cancellation aimed at the run could be absorbed by its
bookkeeping. Replaced with `gather(..., return_exceptions=True)`: a capture must never
outrank the outcome it accompanies.

**5 · The DST test claimed a refusal it was not reaching.** The name and comment said the
loop refused the *spawn*; the workspace is created off the loop, so what fired was the
thread-offload refusal, one step earlier. The test now asserts the message it actually
gets, and a second test pins the spawn refusal the adapter's fail-loud rests on.

**Two things the gates taught, worth recording.** The contract, its mock, the adapter and
the docs page cannot land in separate commits: the mock-coverage guard fails a dep key with
no oracle, and the docs-floor gate fails a page outside the nav — each on the commit that
introduces half the pair. And the adapter module could not be called `subprocess.py`:
bandit reads the import as the stdlib module and flags every importer. It is `process.py`,
which is what the thing is.

**Evidence.** `just quality` 18/18 green. `pytest tests/unit` 13,529 passed, 7 skipped.

## Self-audit round 2 — 2026-09-09

Sabotage before coverage, in that order, then the fixes each produced.

**The sweep started at 25 of 32 killed, and every survivor was a finding.** Five were
test gaps, and four of those were the same gap: **the kill tests asserted the label, not
the kill.** Removing the `SIGKILL` that follows `SIGTERM`, removing the kill on timeout,
and removing the kill on cancellation all left the suite green — because each test checked
`outcome == "killed_timeout"` and then waited out the child's own 30-second sleep, which
produces exactly that string. The docstring at the top of that file says a killed process
is only killed if the pid is gone; the tests did not. They now measure elapsed time against
the child's lifetime, and the cancellation test has the child write a marker *outside* the
workspace after the cancel, so a survivor leaves proof.

The fifth: **the storage refusal was proven by the wrong error.** With the pre-flight
check removed the run still failed — at collection time, after the program had already
run, from the same error code. The test now asserts no child ran at all.

Two more were plain gaps: an escaping `ProgramPayload.filename`, and the request narrowing
the output cap (the existing test only tried to *widen* it, which the ceiling ignores
either way).

**One survivor is an equivalent mutant.** `if kept < cap:` guards a slice that is already
empty once the cap is reached — `chunk[:0]` keeps nothing — so removing the guard changes
speed and not behaviour. Recorded rather than "fixed": a test cannot kill it, and pretending
otherwise would mean writing one that asserts something else.

**Coverage found what the sweep could not.** Patch coverage was 96.9% and the gaps were
real: a duplicate `ConfigurableMockSandbox` in the mock adapter module that nothing used —
the deps module builds the one in `execution/factories.py`, so a reader importing the other
would have wired a class the framework never calls. Deleted. Also uncovered and now tested:
the negative-`kill_grace` refusal, the capabilities property (as opposed to the module
constant), a plain string env value, a glob matching a directory, `_end` against an
already-exited child, and the drain's failed-reader path.

**Also caught, and this one is mine to remember:** `ruff check --fix` over
`tests/unit/test_forze/` rewrote three unrelated test files. Reverted immediately; the rule
is per-file, not per-directory.

**Evidence after the fixes.** Sabotage: 32 mutations, **31 killed, 1 equivalent**. Patch
coverage of the three new modules **100% statements and 100% branches**. `just quality`
18/18. `pytest tests/unit` 13,553 passed, 7 skipped.

## Self-audit round 3 — 2026-09-09

Re-audit of round 2's own changes, and a second read of the adapter with them in place.
Two findings, both surface, both fixed.

**1 · Two adapters refused streaming at different moments.** The base adapter's
`run_stream` was a plain function that raised when *called*; the mock's is an async
generator, so it raises at the first step of the iteration. Same contract, same refusal,
two places a caller's `try` has to be — and the kind of difference that is discovered by
having written the wrong one. The base adapter is an async generator now, and the test
iterates rather than calling. It also removes a `raise AssertionError("unreachable")` from
`src/`, which was the shape of the thing the no-assert rule exists to keep out.

**2 · A killed run's declared outputs were collected, and nothing said so.** Collection
runs after the kill path as well as the clean one, which is right — a half-written artifact
is usually the useful part of a run that did not finish — but it was behaviour nobody had
written down or tested. Pinned with a test that times a run out mid-write and reads the
partial artifact back from storage, and stated in both the adapter's docstring and the
docs page's limits.

**Verification after the fixes.** Sabotage re-run: 32 mutations, 31 killed, the one
survivor still the equivalent mutant recorded in round 2. Patch coverage 100% statements
and 100% branches. `just quality` 18/18.

### The round's other findings — 2026-09-09

Ten more, all fixed on the branch, none of them a departure: each is a defect against a
decision the RFC already made. Ranked by what they cost.

**1 · The isolation gate read every unknown provenance as trusted.** `validate_provenance`
returned early unless the value was exactly `"untrusted"`, so a typo, an empty string or a
spec rebuilt from JSON skipped the check that §1 calls the plane's single most valuable
line. `Provenance` is a `Literal`: mypy enforces it and the interpreter does not, so the
vocabulary had to be enforced at the gate or nowhere. Only `"trusted"` passes without a
containment question now, and anything outside the two words is refused with its own code.

**2 · The mock made that refusal nowhere at all.** The real adapter refuses an untrusted
spec when the port resolves; `ConfigurableMockSandbox` did not, so an untrusted spec on a
route standing in for a non-isolating backend passed every simulation and would have failed
only once deployed. That is the mock↔real divergence pointed the wrong way — a mock
stricter than production fails a correct wiring, a mock laxer than production passes a
broken one.

**3 · A stalled stdin write held the worker forever.** The write ran before the budgeted
wait and `drain()` has no timeout of its own, so a child sent more than a pipe buffer that
then stopped reading left the write pending with no ceiling applying, no kill running and a
live child on a task that never returned. Reproduced by sending 4 MiB to a sleeper; the
test bounds elapsed time rather than asserting the outcome label, which a run that merely
took the long way round would also produce.

**4 · A symlink carried a host file out as a declared artifact.** `is_file()` and
`read_bytes()` both follow one, so `out.txt -> /etc/shadow` dropped beside the real output
was uploaded under a workspace-relative name — a file that was never in the workspace,
leaving through the channel that exists for the ones that were, against row 6.

**5 · Staging spent no budget.** The ceiling was computed before the workspace and the
child got all of it regardless of how long downloading the declared inputs took, so a route
ceiling could be exceeded by the storage plane's latency. The budget is a deadline now, and
a run with nothing left after staging returns the kill outcome without spawning.

**6 · The request's mappings stayed mutable.** `frozen=True` freezes the attribute, not the
dict behind it, so a caller could add a `../` name to `input_files` after the check that
would have refused it. Both mappings are frozen through the existing converter.

**7 · Artifact collection had no ceiling** while captured output did, so one child writing
one large declared file could take the worker's memory. The route carries a total now and
names what it skipped, because an artifact missing from the result and one the child never
wrote look identical from the outside.

**8 · A cancellation during workspace creation leaked the workspace.** The directory is made
off the loop, so cancelling inside that await left the thread to create it with the path
discarded and the cleanup `finally` never entered — in an adapter whose docstring claims
every exit path.

**9 · The output cap said stdout+stderr and gave each reader the whole number.** Kept the
behaviour and corrected the contract: per stream is what a debugger wants, since a chatty
stdout spending stderr's budget truncates away the traceback that explains the run.

**10 · A backslash passed the workspace-name check.** `PurePosixPath` reads it as an
ordinary character, so `..\escape` was one innocent component. Not reachable as shipped —
the project declares no Windows support — but refused now, since the value object should not
have to know what will join the path.

**Two refuted.** That the docs nav points at a missing page: the page is added by the same
commit, and the docs-floor gate passes. And that §4 and §7 contradict the decision rows
appended to the same file: that is this repository's convention, stated in `rfcs/INDEX.md` —
the prose is never edited to agree with what was built, and the row names the section it
overrides.

**Evidence.** `just quality` 18/18 green. `pytest tests/unit` 13,572 passed, 7 skipped.
Each fix was verified red first by reverting it and re-running the test that covers it.

## Review round 2 — 2026-09-09

Five findings, all fixed, and four of them are the same defects as round 1 reached through
a door the first fix left open. That is the finding worth keeping: a fix aimed at the case
the reviewer named, rather than at the class it belongs to, closes one path and leaves the
siblings. No departures; nothing here contradicts a decision the RFC made.

**1 · The frozen mapping was not frozen when it arrived frozen.**
`MappingConverter.frozen` returned an existing `MappingProxyType` unchanged, and a proxy is
read-only from the outside while saying nothing about who still holds the dictionary behind
it. A caller passing one kept editing a field round 1 had just made immutable — the whole
point of that fix, defeated by the one input shape it did not copy. Fixed in the shared
helper rather than at the field: every user of it wanted the same guarantee, and the next
one will not have to rediscover this.

**2 · The workspace-name check refused a backslash and accepted `C:/outside`.** The same
disagreement round 1 identified — an absolute path where it is read as one, a directory
name to `PurePosixPath` — and only half of it was closed.

**3 · Collection skipped a symlink and followed a symlinked directory.** The final-component
check does nothing about `linked/*.txt` where `linked` is the link, which puts host files
under workspace-relative names just as directly. Every resolved path must now land inside
the resolved workspace. Recorded plainly rather than overclaimed: resolve-then-open leaves
a race a per-component `O_NOFOLLOW` open would close, and this tier confines nothing anyway,
so the check bounds the declared-output channel rather than the process.

**4 · The artifact ceiling was a byte ceiling only.** `sorted(workspace.glob(pattern))`
materializes every match before any budget applies, and a byte budget never fires on files
with no bytes — so a child writing very many empty matches spent the worker on the match
list. A pattern over the route's count is abandoned whole rather than truncated, because
`glob` has no defined order and its first *N* is a different answer every run. The read is
one bounded read through a descriptor rather than `stat` then `read_bytes`, which closes a
window that is real here rather than hypothetical: this adapter declares
`reaps_descendants=False`, so a descendant can outlive the kill and still be writing.

**5 · Staging was charged against the budget but not bounded by it.** A download that never
returns held `run()` open past every ceiling the route declares. It runs inside
`asyncio.timeout` now. Collection deliberately does not get the same treatment: it runs
after a kill on purpose, and cancelling it once the budget is spent would discard the
half-written artifact that behaviour exists to keep. A cancellation-aware storage contract
with partial-upload cleanup was declined as out of scope — it is a `StorageCommandPort`
change every consumer of the plane shares, not one this adapter should keep a private copy
of.

**Evidence.** `just quality` 18/18 green. `pytest tests/unit` 13,577 passed, 7 skipped.
Each fix reverted and its test re-run red first.

**Drift count: 1.** Unchanged from the previous count; none of the five is a departure.
